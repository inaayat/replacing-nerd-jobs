Pin it before you forget it

Sticky Notes is a digital cork board for the stuff that never makes it into a todo app: half-baked ideas, links you meant to read, errands, and the name of that restaurant. Drop notes on the board here, or capture them from anywhere with the browser extension.

Chrome extension

Capture a thought from any tab without switching apps. Notes land in the extension first, then merge onto this board the next time you open it.

  1. Download or clone this repo and open sticky-notes/extension/.
  2. In Chrome, go to chrome://extensions, enable Developer mode.
  3. Click Load unpacked and select the extension folder.
  4. Use the toolbar icon, the right-click menu, or Alt+Shift+N to pin a note.
